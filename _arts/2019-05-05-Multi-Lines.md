There are 8 distinct lines. But in the middle, there are lines overlapping -- to be exact 4. In the middle, the lines' vectors were generated using Perlin Noise. Perlin Noise was created in the 80s by Kent Perlin. It is used to generate something that looks random but natural, like terrains. The obvious example is Minecraft.
