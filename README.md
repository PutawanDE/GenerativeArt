# Generative Art Personal Gallery of PutawanDE

Arts made using Processing, and p5.js.  
Site made using Jekyll.  
Hosted using Github pages.  

## How to set up?
1. Install Jekyll: https://jekyllrb.com/docs/installation/  
   Note: During `ridk install`, choose 3 - MSYS2 and MINGW development toolchain.
2. Clone the repo.
3. Inside the repo, run `bundle install` to install necessary bundlers.

## How to run locally?
Use command `bundle exec jekyll serve --baseurl=`.
